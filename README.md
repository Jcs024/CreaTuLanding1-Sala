# 🎮 Ecommerce de Videojuegos – Juan Sala
Este proyecto es un ecommerce de venta de videojuegos desarrollado como práctica y aprendizaje, con el objetivo de aplicar conceptos de React, manejo de rutas, consumo de datos desde Firebase, y un diseño amigable para el usuario.

## 🚀 Tecnologías utilizadas
JavaScript

React

HTML

CSS

Firebase (^12.0.0) – Base de datos y autenticación

react-icons (^5.5.0) – Iconos para la interfaz

react-router-dom (^7.6.3) – Manejo de rutas y navegación

react-spinners (^0.17.0) – Indicadores de carga

sweetalert2 (^11.22.2) – Alertas y notificaciones interactivas

## 🛠 Funcionalidades principales
Listado de videojuegos y tarjetas de regalo.

Búsqueda y filtrado de productos.

Carrito de compras con persistencia de datos.

Alertas visuales al agregar o modificar productos en el carrito.

Integración con Firebase para datos dinámicos.

Navegación fluida gracias a react-router-dom.

## Instalación
1. clona el repositorio ejecutando en tu consola
    git clone https://github.com/Jcs024/ProyectoFinal-Sala.git
2. descarga las dependencias ejecutando en tu consola
    npm install
3. Finalmente, ejecuta en tu consola
    npm run dev
